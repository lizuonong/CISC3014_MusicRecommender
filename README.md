# CISC3014 课程项目 - 音乐推荐系统

## 项目信息
- **课程**: CISC3014 Information Retrieval and Web Search
- **学期**: 2026-1 Fall
- **截止日期**: 2026年12月17日

## 项目概述
本项目实现一个基于协同过滤的音乐推荐系统，包含：
1. **数据爬取**: 使用 Scrapy 从音乐网站爬取歌曲数据
2. **推荐算法**: 基于用户的协同过滤 (User-based CF)
3. **可视化展示**: Jupyter Notebook 展示推荐结果
